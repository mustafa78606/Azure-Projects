# ☁️ Azure Cloud Computing & Data Fundamentals Project 🚀

## 📖 Project Overview
As part of my **Data Technician Bootcamp**, I completed a hands-on **Microsoft Azure** project, developing practical knowledge of cloud computing, data services, and cost management. Through a combination of **Microsoft Learn** modules and **Skillable labs**, I explored real-world Azure solutions and gained experience working with cloud technologies used by modern organisations.

---

## 🚀 Skills Developed

### ☁️ Microsoft Azure
- ✅ Understanding cloud service models: **IaaS, PaaS, and SaaS**
- ✅ Exploring Azure services including:
  - 🗄️ Azure SQL Database
  - 📦 Azure Storage Accounts
  - 🔄 Azure Data Factory
  - 📊 HDInsight
  - 📈 Operational Insights
  - 🌐 Microsoft Fabric
- ✅ Learning cloud deployment models:
  - 🌍 Public Cloud
  - 🏢 Private Cloud
  - 🔗 Hybrid Cloud
  - 👥 Community Cloud
- ✅ Understanding scalability, security, and business benefits of cloud platforms

---

### 💰 Azure Cost Management
One of the key activities involved using the **Azure Pricing Calculator** to estimate costs for a cloud-based Business Intelligence solution.

🔹 Selected Azure services required for the solution  
🔹 Calculated estimated monthly cloud costs  
🔹 Analysed pricing and resource requirements  
🔹 Learned how businesses forecast and manage cloud spending  
🔹 Developed awareness of cost optimisation and budgeting strategies

---

#### Key Areas Explored:

- 📊 Data Analytics Services

- ⚙️ Azure Administration Tasks

These hands-on labs helped bridge the gap between theory and real-world cloud implementation.
